# 管理员操作手册

## 登录与导航

访问 `/admin/login/` 登录。登录后可进入：

- `/manage/`：视频共享控制台
- `/manage/upload/`：上传视频
- `/manage/records/`：观看记录
- `/manage/settings/`：系统名称、IP黑名单与当前管理员密码
- `/admin/`：数据库对象和审计信息

Django系统管理页顶部提供“返回控制台”入口。

## 设置系统名称

1. 在控制台点击“系统设置”。
2. 输入新的系统名称并保存。
3. 新名称会显示在授权观看页、控制台、浏览器标题和系统管理后台。

系统名称最多80个字符。修改动作会进入管理员审计日志。

## 设置IP黑名单

1. 打开“系统设置”。
2. 在“IP黑名单”中每行填写一条正则表达式。
3. 保存后，客户端标准化IP只要完整匹配任一规则，其所有动态请求都会返回HTTP 403。

示例：

```text
^203\.0\.113\.25$
^198\.51\.100\.\d{1,3}$
^2001:db8:.*$
```

系统会验证正则语法，每条规则最多200个字符、最多100条。为防止管理员误锁定自己，命中当前管理IP的配置无法保存。生产环境位于Nginx之后时，应设置 `TRUST_PROXY_HEADERS=1`，并仅允许可信代理覆盖 `X-Real-IP`。

命中黑名单的请求会写入 `ip_blacklisted` 安全事件；同一IP一分钟内最多写入一条，避免恶意请求造成审计表快速增长。

## 修改管理员密码

1. 打开“系统设置”。
2. 输入当前密码。
3. 输入并确认符合强度要求的新密码。
4. 点击“修改登录密码”。

修改成功后当前会话保持登录。密码仅保存为Django安全哈希，不保存明文。忘记密码时，由有服务器权限的维护人员使用 `manage.py changepassword 用户名`。

## 上传视频

1. 点击“上传视频”。
2. 填写对观看者有意义的视频名称。
3. 选择 `.mp4` 文件并提交。
4. 等待后台扫描和转码。

Web上传最大默认2GB。系统校验扩展名、MP4容器标识和视频轨道，随后以随机物理文件名保存到 `/video`。页面中的视频名称可独立修改。

## 处理状态

- 等待文件稳定：刚发现文件，等待下一次扫描
- 等待转码：已进入Celery队列
- 正在转码：FFmpeg正在生成HLS
- 可播放：转码完成
- 处理失败：检查错误信息与Worker日志
- 源文件缺失：数据库记录存在，但 `/video` 原文件不存在

后台每分钟扫描一次。大文件转码时间取决于分辨率、时长和服务器性能。

## 编辑视频名称

在视频卡片点击“编辑名称”。修改只影响页面展示，不修改 `/video` 中的随机文件名或既有授权码。

视频卡片同时显示分辨率、时长、大小和上传/发现时间。

## 生成授权码

- 自动生成：一次最多20个安全随机码
- 手工设置：每次一个10位字母或数字
- 可设置生效时间、失效时间和管理员备注

完整授权码只显示一次。系统只保存HMAC摘要和末4位。删除授权码后，既有活动会话立即撤销，历史相同授权码不能重新使用。

## 共享开关

- “停止共享”会让该视频的所有授权码和既有播放会话立即不可用。
- “恢复共享”仅恢复视频级开关；仍然需要处于有效期内的授权码。

## 观看记录

观看记录每页25条，包含：

- 视频名称与授权码尾号
- IP地址
- 授权、开始和最后活动时间
- 累计观看时长与最远播放位置
- 会话状态

