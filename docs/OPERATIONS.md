# 管理员操作手册

## 1. 入口与菜单

访问 `/admin/login/` 登录。管理页面顶部菜单按以下结构组织：

| 一级菜单 | 二级入口 |
| --- | --- |
| 私密视频 | 视频共享控制台、上传MP4视频、视频观看记录 |
| 私密聊天 | 聊天室管理、创建聊天室、聊天参与记录 |
| 系统设置 | 无二级菜单，直接进入系统名称、IP黑名单和管理员密码设置 |
| 系统管理 | Django系统管理、管理员审计日志、安全事件记录 |

Django系统管理顶部提供“返回控制台”。展开一个带二级菜单的一级菜单时，其他菜单会自动关闭。

公开统一入口 `/`、视频观看页和聊天室页都不显示管理菜单，即使管理员同时保持登录。

## 2. 统一授权入口

对外只需提供 `/`：

1. 访问者输入管理员提供的10位授权码。
2. 系统自动识别授权码对应视频或聊天室。
3. 视频码进入观看页；聊天室码进入对应聊天室。

旧 `/chat/` 只保留为跳转到统一入口的兼容路径。统一入口固定显示“私密视频/聊天入口”，不显示后台系统名称。

授权失败的常见原因：

- 授权码错误或不完整
- 尚未到生效时间
- 已过失效时间
- 授权码已删除
- 视频已停止共享或尚未转码完成
- 聊天室已关闭
- 请求IP命中黑名单或触发限流

## 3. 私密视频

### 3.1 上传MP4

1. 选择“私密视频 → 上传MP4视频”。
2. 填写对观看者有意义的视频名称。
3. 选择 `.mp4` 文件并提交。
4. 等待后台扫描和转码。

Web上传默认最大2GB。系统校验扩展名、MP4容器头和视频轨道，成功后以随机物理文件名保存到 `/video`。失败只清理本次请求创建的临时文件。

维护人员也可将媒体文件放入 `/video`。后台每分钟扫描一次，文件连续稳定后才开始处理。

### 3.2 处理状态

| 状态 | 含义 |
| --- | --- |
| 等待文件稳定 | 刚发现文件，等待下一次扫描确认写入完成 |
| 等待转码 | 已进入Celery队列 |
| 正在转码 | FFmpeg正在生成HLS |
| 可播放 | 转码完成，可创建或使用授权 |
| 处理失败 | 查看视频错误信息和Worker日志 |
| 源文件缺失 | 数据库有记录，但原文件已不在 `/video` |

视频卡片显示分辨率、时长、大小以及上传或发现时间。

### 3.3 编辑视频名称

在视频卡片中选择“编辑名称”。修改只影响页面显示，不改变 `/video` 中的物理文件名、HLS目录或既有授权码。

### 3.4 生成授权码

- 自动生成：一次最多20个随机码
- 手工设置：每次设置一个10位英文字母或数字
- 可选：生效时间、失效时间、管理员备注

创建授权码会自动启用视频共享。完整授权码只显示一次；离开结果页后无法恢复明文。

同一视频允许存在多个授权码。手工授权码会同时检查视频和聊天室，不能使用已存在或已删除授权码的历史值。

### 3.5 删除授权码与共享开关

- “删除”授权码后，该码不再显示且相关活动会话立即撤销。
- “停止共享”会让视频所有授权码和既有播放会话立即不可用。
- “恢复共享”只恢复视频级开关，仍需使用处于有效期内的授权码。

### 3.6 观看记录

“私密视频 → 视频观看记录”每页显示25条，包括：

- 视频名称和授权码尾号
- IP地址
- 授权、开始和最后活动时间
- 累计观看时长和最远播放位置
- 当前会话状态

## 4. 私密聊天

### 4.1 创建聊天室

1. 选择“私密聊天 → 创建聊天室”。
2. 填写聊天室名称。
3. 随机选择或手工指定一组小说人物昵称。
4. 选择随机生成或手工设置10位授权码。
5. 在结果页立即复制授权码。

聊天室数量不设应用级上限，聊天室列表每页显示25个。

### 4.2 参与者体验

- 多名访问者可使用同一聊天室授权码进入。
- 每个参与者获得该聊天室内唯一昵称和随机头像，并显示脱敏IP。
- 默认加载最近50条消息，向上滚动每次获取更早50条。
- WebSocket断开时自动重连；重连期间补拉遗漏消息，必要时使用HTTP轮询。
- 点击右上角“退出聊天室”并确认后，当前会话立即撤销并返回统一入口；再次进入需要重新输入授权码。

消息正文永久保存在MySQL，Redis只负责实时广播。

### 4.3 管理聊天室

在聊天室管理列表中可以：

- 关闭或重新开放聊天室
- 更换授权码
- 查看该聊天室聊天记录

关闭聊天室或更换授权码都会撤销现有参与者会话。完整的新授权码只在结果页显示一次。

### 4.4 聊天参与记录

“私密聊天 → 聊天参与记录”每页显示25名参与者：

- 聊天室
- 昵称
- 完整IP
- 进入时间
- 最后活动时间
- 最后发言时间
- 消息数量
- 会话状态

普通聊天室页面只显示脱敏IP；完整IP仅在staff管理页面显示。

### 4.5 聊天记录

在聊天室列表点击“查看聊天记录”。页面按每页50条显示该聊天室消息正文、昵称、IP和发送时间，不混入其他聊天室内容。

## 5. 系统设置

### 5.1 系统名称

系统名称最多80个字符，保存后用于控制台、管理页面浏览器标题和Django系统管理。公开统一授权入口使用固定标题，不展示系统名称。

页面中的“上次修改”信息独立显示，不覆盖系统名称输入框。

### 5.2 IP黑名单

每行一条规则。常用写法不需要反斜杠、`^` 或 `$`：

```text
203.0.113.25
198.51.100.*
2001:db8:*
```

- 完整IP：只匹配该地址
- `*`：匹配任意字符范围
- 旧正则规则：包含正则标记时继续按正则编译并执行完整匹配
- 每条最多200个字符，最多100条

系统会阻止保存能命中当前管理员IP的规则，避免管理员把自己锁在系统外。命中黑名单的请求返回HTTP 403并记录 `ip_blacklisted` 安全事件，同一IP一分钟最多记录一次。

生产部署在Nginx之后时，只有在请求无法绕过可信代理的前提下才能设置 `TRUST_PROXY_HEADERS=1`。

### 5.3 修改管理员密码

1. 输入当前密码。
2. 输入并确认符合Django强度要求的新密码。
3. 点击“修改登录密码”。

成功后当前会话保持登录。密码只保存安全哈希。忘记密码时，由服务器维护人员执行：

```bash
/opt/private-video/.venv/bin/python manage.py changepassword 用户名
```

- 查看安全事件和管理员审计
- 验证管理员账号和冒烟测试凭据

## 7. 常见问题

### 授权码刚生成却提示无效

确认生效时间和服务器时区，检查视频是否“可播放”且共享已启用，或聊天室是否开放。授权码必须正好10位。

### 页面提示CSRF验证失败

刷新统一入口后重试；若持续出现，检查访问域名、HTTPS协议、 `CSRF_TRUSTED_ORIGINS`、代理头和浏览器Cookie策略。

### 聊天室显示“连接中断，正在重连”

检查Daphne服务、Nginx `/ws/chat/` 代理、Redis连接和 `USE_REDIS_CHANNEL_LAYER=1`。浏览器必须能携带根路径访客Cookie。

### 上传后一直没有转码

检查Beat是否每分钟调度、Worker日志、FFmpeg/FFprobe、目录权限和磁盘空间。
